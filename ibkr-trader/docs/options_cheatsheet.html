Payoff at expiry (profit, per share)

PositionProfit
Long callmax(ST−K, 0) − c
Short callc − max(ST−K, 0)
Long putmax(K−ST, 0) − p
Short putp − max(K−ST, 0)

Pattern: long = intrinsic − premium; short = flip the sign. Calls use ST−K, puts use K−ST. Rigorous "profit" compounds the premium: … − c·erT.

Put–call parity (European, no div.)

c + K·e−rT = p + S₀

Rearranged: c − p = S₀ − K·e−rT. A long call + short put at the same K = a synthetic forward on the stock. With dividends, replace S₀ with S₀−D (or S₀e−qT).

The Box Spread (synthetic loan)

Pick K₁ < K₂, same expiry. Stack two verticals:

  • Bull call spread: long call K₁, short call K₂
  • Bear put spread: long put K₂, short put K₁

Combined payoff at expiry, for any ST:

max(ST−K₁,0) − max(ST−K₂,0)
  + max(K₂−ST,0) − max(K₁−ST,0)  = K₂ − K₁

The ST terms cancel → a fixed payoff = a zero-coupon bond. No-arbitrage cost today:

Box value = (K₂ − K₁)·e−rT

  • Long box (pay debit, collect K₂−K₁ later) = lending at the implied rate.
  • Short box (collect credit now, pay K₂−K₁ later) = borrowing.

Keep it risk-free: use European, cash-settled index options (SPX/XSP) — American options can be assigned early and break the box. Hold to expiry.

2. Box as a loan — K₁=5000, K₂=5100, T=0.5 yr, r=5%:

  • Guaranteed payoff = 5100−5000 = 100 (= $10,000 / box ×100).
  • Fair cost = 100·e−0.05×0.5 = 97.53 (≈ $9,753).
  • If you can buy (long) it for 97.0: you lend $9,700, get $10,000 in 6 mo → implied yield ≈ 6.3% > 5% ⇒ arb (lend above market).
  • If you sell (short) it for 98.0: you borrow $9,800, repay $10,000 → implied cost ≈ 4.1% < 5% ⇒ cheap financing.
